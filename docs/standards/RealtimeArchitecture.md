# Realtime WebSocket & Socket.IO Gateway Architecture

**System Name:** FinTrack Pro Enterprise AI Finance Management Platform  
**Document Type:** Realtime Streaming & Communication Specification  
**Author:** Lead Backend Engineer & Realtime Systems Specialist  
**Status:** Approved for Implementation  

---

## 1. Realtime Architecture & Gateway Design

Real-time streaming features (AI conversational response streaming, live report export progress notifications, share price tick updates) are powered by **Socket.IO over WebSockets with HTTP long-polling fallback**.

```
[Browser Client] <===> [WebSocket / WSS] <===> [Socket.IO Gateway]
                                                       │
                                     ┌─────────────────┴─────────────────┐
                                     ▼                                   ▼
                          [Tenant Room Broadcast]             [User Specific Channel]
```

---

## 2. Realtime Event Channels & Payloads

1. **`dashboard:metrics_updated` (Tenant Room):** Emitted when new transaction CSVs are uploaded, triggering real-time chart refreshes across active dashboard viewers.
2. **`report:progress` (User Channel):** Emitted by background `pptWorker` jobs to inform the user of slide generation progress (0% to 100%).
3. **`ai:stream_chunk` (User Channel):** Streams token chunks generated by the AI assistant directly into the chat UI.
4. **`share:price_tick` (Global Room):** Broadcasts stock ticker price updates during market trading hours.

---

## 3. Session Authentication & Reconnection

Socket.IO connection handshake validates the user's HttpOnly session token. If session validation fails, the WebSocket connection is instantly terminated with code `4001 Unauthorized`.
