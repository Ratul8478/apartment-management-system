# Support Manual & Escalation Matrix — FinTrack Pro

## 1. SLA Definitions & Severity Levels

- **Severity 1 (Critical - Outage)**: System down or key data loss. SLA Response < 15 mins. SLA Resolution < 2 hours.
- **Severity 2 (High - Core Feature Degraded)**: AI completion down or billing checkout failing. SLA Response < 1 hour. SLA Resolution < 6 hours.
- **Severity 3 (Medium - Minor Defect)**: UI layout glitch or non-critical report export delay. SLA Response < 4 hours. SLA Resolution < 24 hours.
- **Severity 4 (Low - Feature Inquiry)**: General user question or documentation request. SLA Response < 1 business day.
