# API Endpoints & Deployment Specification — FinTrack Pro

- **Health Probe**: `GET /api/health`
- **Authentication**: `/api/auth/*` (Login, Register, Session, MFA)
- **Financial Ledger**: `/api/finance-records/*`
- **OCR Processing**: `/api/ocr/process-invoice`
- **Billing & Subscriptions**: `/api/stripe/*` & `/api/billing/*`
- **AI Financial Intelligence**: `/api/ai-chat`
