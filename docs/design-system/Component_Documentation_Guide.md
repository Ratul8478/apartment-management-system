## 1. Component Documentation Template

Every component in `components/ui/` or `features/*/components/` MUST include JSDoc comments detailing:
- Component Purpose.
- Supported Props Contract.
- Accessibilty ARIA expectations.
- Storybook Story variants (`Default`, `Disabled`, `Loading`, `Error`).
